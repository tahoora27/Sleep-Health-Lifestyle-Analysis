# Sleep Health and Lifestyle Data Analysis

## Project Overview
This project analyzes the Sleep Health and Lifestyle dataset to understand the relationship between sleep patterns and lifestyle factors such as stress level, physical activity, and heart rate.

## Dataset
The dataset contains 400 records with 13 attributes including:
- Gender
- Age
- Occupation
- Sleep Duration
- Quality of Sleep
- Physical Activity Level
- Stress Level
- BMI Category
- Blood Pressure
- Heart Rate
- Daily Steps
- Sleep Disorder

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Finding patterns and insights

## Key Insights
- Higher stress levels are associated with poor sleep quality.
- Physical activity has a positive effect on sleep duration.
- Individuals with sleep disorders tend to have higher stress levels.

## How to Run the Project
1. Download the dataset.
2. Open the `.ipynb` file in Jupyter Notebook.
3. Run the cells to reproduce the analysis and visualizations.
